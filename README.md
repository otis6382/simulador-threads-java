# Simulador de Threads em Java

Atividade da disciplina de Arquiterura de Computadores, da faculdade Nova Roma e professor Thomás Oliveira Tabosa.

## Descrição

Programa Java que executa três threads concorrentemente, permitindo que o usuário configure o intervalo de execução de cada uma.

O programa valida os tempos informados e solicita um novo valor quando o usuário digita um número menor ou igual a zero.

## Tecnologias

- Java
- Threads
- Scanner

## Execução

Compile os arquivos:

```bash
javac -d bin src/Main.java src/ExemploThread.java
```

Execute:

```bash
java -cp bin Main
```
